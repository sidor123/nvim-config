# Личный конфиг Neovim

Для Neovim 0.12. При первом запуске на новой машине встроенный `vim.pack` предложит установить пакеты через Git. Их ревизии записаны в `nvim-pack-lock.json`.

| Пакет | Для чего используется |
| --- | --- |
| mini.nvim | Поиск файлов, текста и буферов, текстовые объекты, операции со скобками и кавычками, строка состояния |
| gitsigns.nvim | Отметки изменений, просмотр diff и работа с отдельными фрагментами |
| conform.nvim | Форматирование через StyLua или подключённый LSP |
| tokyodark.nvim | Тема из старого конфига |
| alpha-nvim | Стартовый экран с рисунком, цитатой и кнопками |
| neo-tree.nvim, nvim-web-devicons | Дерево файлов и иконки типов файлов |
| fidget.nvim | Индикатор работы LSP |
| todo-comments.nvim | Подсветка TODO и FIXME, поиск по проекту через `:TodoQuickFix` |
| indent-blankline.nvim | Вертикальные направляющие отступов |
| which-key.nvim | Подсказки при вводе сочетаний клавиш |
| plenary.nvim, nui.nvim | Зависимости Neo-tree и todo-comments |

Для отображения иконок выбери Nerd Font в настройках терминала.

## Клавиши

`Space` служит лидером. Команды поиска работают от текущего каталога Neovim. Для поиска текста по проекту используется `rg`, если он установлен.

| Клавиши | Действие |
| --- | --- |
| `Space e` / `Space E` | Открыть или закрыть боковую панель Neo-tree / переключить дерево в текущем окне |
| `Space sf` / `Space sg` / `Space sw` | Найти файл / текст в проекте / слово под курсором |
| `Space Space` / `Space /` | Выбрать буфер / найти строку в текущем буфере |
| `Space s.` / `Space sr` | Недавние файлы / продолжить поиск |
| `Space sk` / `Space sh` | Найти сочетание клавиш / статью справки |
| `Ctrl-h/j/k/l` / `Space c` | Перейти в соседнее окно / закрыть текущее |
| `gd` / `gr` / `gI` | Определение / использования / реализация символа |
| `K` / `Ctrl-k` в режиме вставки | Документация под курсором / подсказка сигнатуры функции |
| `Space D` / `Space ds` / `Space ws` | Определение типа / символы файла / символы проекта |
| `Space rn` / `Space ca` / `Space q` | Переименовать символ / выбрать действие LSP / открыть диагностику буфера |
| `Ctrl-Space`, затем `Tab` или `Shift-Tab`, `Enter` | Открыть LSP-дополнение в режиме вставки, выбрать и подтвердить вариант |
| `Space f` | Отформатировать буфер или выделение |
| `]c` / `[c` / `Space hp` | Следующее изменение / предыдущее / просмотр фрагмента |
| `Space hs` / `Space hr` | Добавить фрагмент в индекс Git или убрать из индекса / сбросить изменение |

## Языковые инструменты

Встроенный LSP запускает `clangd` для C/C++, `gopls` для Go, `kotlin-lsp` для Kotlin, `lua-language-server` для Lua и `texlab` для LaTeX и BibTeX, когда найден соответствующий исполняемый файл. Для Kotlin отключён запуск в одиночном файле: серверу нужен корень проекта. Сначала проверяется системный `PATH`, затем каталог инструментов Mason от предыдущей установки. Состояние клиентов можно проверить командой `:checkhealth vim.lsp`.

Подсветка синтаксиса C, C++, Go и Kotlin включается через Tree-sitter. На новой машине для установки парсеров нужны компилятор C и `tree-sitter` CLI версии 0.26.1 или новее; Neovim скачает парсеры при первом запуске.

`gopls` и Kotlin LSP устанавливаются отдельно от Neovim. Для Go установи `gopls` согласно [официальной инструкции](https://go.dev/gopls/#installation). Kotlin LSP от JetBrains пока находится в alpha; установка описана в [официальной документации](https://kotlinlang.org/docs/kotlin-lsp.html). Если программа сервера отсутствует в `PATH`, Neovim пропустит её запуск.

При сохранении Lua используется `stylua`, для других поддерживаемых файлов доступно форматирование через LSP. В C/C++ форматирование запускается вручную через `Space f`. Команда `:ConformInfo` показывает доступный форматтер для текущего файла.
